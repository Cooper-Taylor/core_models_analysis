# AI Reaction-Directionality Curation (Claude Opus 4.8 via Argo)

AI-generated directionality calls for ModelSEED reactions, produced with
**Claude Opus 4.8** through the **Argo gateway** (Argonne's internal LLM service).
This is a regeneration of KBUtilLib's `AICurationCacheReactionDirectionality.json`
with a newer model, plus an expansion to the full ModelSEED database.


## Schema

JSON object keyed by ModelSEED base reaction id (e.g. `rxn00077`). Each value:

```json
{
  "errors": [],
  "directionality": "forward | reverse | reversible | uncertain",
  "other_comments": "Free-text rationale from the model.",
  "confidence": "high | medium | low | none"
}
```

All entries are normalized to exactly these four fields. Where Opus 4.8 emitted an
extra key (e.g. `directionality_note`), its content was folded into `other_comments`.

## How it was generated

- **Model / route:** `claudeopus48` (Claude Opus 4.8) via the Argo legacy chat
  endpoint `https://apps.inside.anl.gov/argoapi/api/v1/resource/chat/` — the same
  mechanism `KBUtilLib/argo_utils.py` already uses. `ai_curation_utils.py` was
  modified so the `argo` backend defaults to `claudeopus48` and sends `max_tokens`
  (Claude on Argo requires it). See that file's `__init__` / `_payload`.
- **Method:** the real `AICurationUtils.analyze_reaction_directionality()` — same
  system prompt, JSON parsing, and cache schema as upstream.
- **Reactions:** rebuilt as `cobra` objects directly from
  `/scratch/ctaylor/ModelSEEDDatabase/Biochemistry/reaction_*.json` (no `modelseedpy`
  needed). Each reaction is presented in canonical reversible orientation and the
  model judges direction (the "canonical" mode).
- **Driver:** `regen_directionality.py` — thread-pooled, **resumable** (skips ids
  already in the output file), checkpoints periodically, robust JSON extraction
  (handles fenced / trailing-prose responses).
- **Environment:** conda env `core_models_analysis`
  (`/mnt/homes/ctaylor/conda/miniforge3/envs/core_models_analysis/bin/python`) — has
  `cobra` + `httpx`. (The `KBUtils_Local/.venv` does **not** have `cobra`.)

## curated_8848 — results

Regeneration of the prior file's reaction set (8,848 ids) with Opus 4.8.

| Metric | Value |
|---|---|
| Regenerated | **8,834 / 8,848** |
| Directionality agreement vs. prior file | ~79.2% (6,993 / 8,832 shared) |
| forward / reversible / reverse / uncertain | 6,373 / 1,791 / 373 / 296 |

The ~21% that differ from the prior file are genuine model-judgment changes — the
point of regenerating with a newer model. `rxn03572` was declined by Opus 4.8 and
filled with an **Opus 4.7** fallback (tagged in its `other_comments`).

### 14 not regenerated

- **10 non-ModelSEED keys** (`DgoA`, `rxnCYTCBB3`, `rxnIronOx1`, `rxnIronOx2`,
  `sul00002/3/4/8`, `sul00010`, `rxn08502_e0`) — these were in the prior file but
  are not reactions in the ModelSEED DB (custom model ids), so they can't be rebuilt.
- **4 safety refusals** (`rxn10703`, `rxn10716`, `rxn10727` — *M. tuberculosis*
  phthiocerol dimycocerosate virulence-lipid synthesis; `rxn26361` — molybdenum
  cofactor cytidylyltransferase). Declined by **both Opus 4.8 and Opus 4.7**
  (`stop_reason: "refusal"`). Recoverable only with a non-Anthropic Argo model
  (e.g. `gpt5`), which would change the model for those entries.

## Full run — all ModelSEED reactions (`all_modelseed/`)

ModelSEED DB = **56,012** reactions (7,609 obsolete, 10 with empty stoichiometry).
The full run covers all **56,002 buildable** reactions (obsolete included, per
"all 56k"). To exclude obsolete later, filter on `is_obsolete` in the driver.

Reproduce / resume:

```bash
cd /scratch/ctaylor/ai_curation_argo
PY=/mnt/homes/ctaylor/conda/miniforge3/envs/core_models_analysis/bin/python
$PY -u regen_directionality.py --source all --limit 0 --workers 12 \
    --out /scratch/ctaylor/core_models_analysis/data/ai_curation/all_modelseed \
    --checkpoint-every 200
```

Re-running the same command skips reactions already present and only does the rest.
Progress (count updates per checkpoint):

```bash
python3 -c "import json;print(len(json.load(open('all_modelseed/AICurationCacheReactionDirectionality.json'))),'/ 56002')"
```

Expect a large fraction of safety refusals across 56k reactions (sensitive
biochemistry); those are logged and skipped.

## Caveats

- **Argo large-run policy:** the Argo docs ask users to coordinate large/long-running
  automated runs with `mdearing@anl.gov`. The full run is ~56k calls (many hours).
- **Refusals:** Opus models decline some sensitive reactions; those rows are absent.
- **Orientation:** canonical/reversible presentation — does not reproduce the prior
  file's legacy `reaction_inverted` flag.
- **Provenance:** values are AI estimates, not experimentally verified.
