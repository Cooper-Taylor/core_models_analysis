# Impact of the inherited-KEGG-id defect on the original dGPredictor

Generated by `scripts/plot_kegg_fix_impact.py` from ModelSEED **dev @ 49563c6f**
(the live dev branch, `/scratch/ctaylor/tmp/devsnap2`). Statistics in
`kegg_fix_stats.tsv`.

## The defect being tested

The original dGPredictor scores a *KEGG* reaction, so every ModelSEED reaction
had to be matched to a KEGG id first. The script that did that (in the
freiburgermsu dGPredictor repository, **not** in ModelSEED) never reset its
"last seen KEGG id" variable, so a ModelSEED reaction with **no** KEGG alias
silently inherited the id of the preceding reaction in file order. On dev this
affects **17,271 of the 27,715** stored `thermodynamics.dGPredictor` records
(62%), of which **7,466** have been promoted into the canonical
`deltag`/`deltagerr`/`reversibility`.

## What "fixed" means here

No re-prediction was necessary. Where a reaction's staged KEGG id **is** a
genuine ModelSEED alias, the stored value already belongs to the right reaction
— the staged ids and the aliases never *conflict*, they are only ever *absent*.
So the repaired upstream script (`dG_prediction_modelseed_dev_branch_file_run.py`,
which sets `kegg_id_str = None` each iteration) would emit exactly the current
values for those reactions and nothing for the rest.

Applying the fix therefore = drop the 17,271 reactions listed in
`results/thermo_agreement/dgpredictor_kegg_mask.json` from the dGPredictor
series. Every other source is left untouched.

## The control

Removing points can raise a correlation on its own, so each pair is also drawn a
third way: a **random** subset of the full set, of exactly the same size as the
fixed set, repeated 25 times with a fixed seed. If the improvement were merely
"fewer points", the control would move as much as the fix does.

## Point colours

Each source's own ΔG′° is pushed through the unmodified ModelSEED cascade and
the two resulting operators are compared:

| category | meaning |
|---|---|
| **No change** (gray) | identical call — both `=`, **or the same irreversible direction** (both `>` or both `<`) |
| **Reversible → Irreversible** (blue) | `=` then `>`/`<` |
| **Irreversible → Reversible** (orange) | `>`/`<` then `=` |
| **Irreversible → Irreversible** (green) | `>` vs `<` — both irreversible, in **opposite** directions. The only genuine direction conflict. |

This is deliberately stricter than `plot_thermo_source_dg_scatter.py`, which
puts every both-irreversible pair in the last category regardless of direction,
and therefore colours perfect agreement identically to a reversal. Gray is drawn
smaller and more transparent because it is now the bulk of every panel.

## Results

| pair | as shipped | KEGG fixed | random control (mean ± SD) |
|---|---:|---:|---:|
| Group Contribution vs dGPredictor | r = 0.22 | **r = 0.81** | 0.215 ± 0.013 |
| eQuilibrator vs dGPredictor | r = 0.26 | **r = 0.77** | 0.266 ± 0.019 |
| dGPredictor vs dGPredictor-ModelSEED | r = 0.27 | **r = 0.83** | 0.274 ± 0.016 |

The fixed values sit **26–45 standard deviations** beyond what removing the same
number of *random* reactions produces. Typical error improves too — median |Δ|
against Group Contribution falls 9.11 → 5.69 kcal/mol, against eQuilibrator
4.75 → 2.83 kcal/mol.

The control panels are visually indistinguishable from the as-shipped panels;
only the fixed panels collapse onto the diagonal.

## Direction reversals — arguably the more important number

A ΔG disagreement only changes an FBA model when it flips the reaction's
direction. Counting only the green category (both sources irreversible, opposite
directions):

| pair | as shipped | KEGG fixed | random control |
|---|---:|---:|---:|
| Group Contribution vs dGPredictor | 507 (2.7%) | **158 (1.7%)** | 247 (2.7%) |
| eQuilibrator vs dGPredictor | 542 (3.9%) | **176 (2.2%)** | 320 (4.1%) |
| dGPredictor vs dGPredictor-ModelSEED | 397 (1.9%) | **70 (0.7%)** | 189 (1.9%) |

The fix roughly halves the reversal *rate* in every pair; the random control
leaves it unchanged. For reference, pairs that do not involve the original
predictor were always low — Group Contribution vs eQuilibrator 1.5%,
eQuilibrator vs the retrain 0.5% — so the excess is specific to the mis-mapped
values.

## Reading the as-shipped panels

The horizontal and vertical stripes are the defect made visible: a single
inherited ΔG value repeated across hundreds of unrelated reactions traces a
straight line, because one coordinate is constant while the other varies. Across
the 9,274 mis-mapped reactions the original carries only **956 distinct ΔG
values** (10.3%), against 3,561 from the retrain over the same reactions.
