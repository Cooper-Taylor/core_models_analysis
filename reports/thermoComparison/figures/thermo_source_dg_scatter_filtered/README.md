# ΔG′° source scatter plots, sliced by predicted error / tolerance

Generated by `scripts/plot_thermo_source_dg_scatter_filtered.py` (no arguments,
~2m20s). Cascade code from the working `ModelSEEDDatabase` checkout.

**Data: ModelSEED `dev` @ 49563c6f**, snapshotted to `/scratch/ctaylor/tmp/devsnap2`.
That is *after* `ad34d6ab` "Rebuild GC energies under Convention A (Chris 2010
formalism)", so Group Contribution here is the rebuilt data — see the section on
it below. eQuilibrator and dGPredictor-ModelSEED are byte-identical to the
earlier `34992d39` snapshot. ê comes from `results/eq_vs_dgpms_gcA/`, refitted
against the rebuilt GC (the previous fit no longer describes these values).

Thresholds T ∈ {0.5, 1, 2, 5, 10, 20} kcal/mol; a reaction passes iff **both**
sources are ≤ T. Every panel carries its own key, and the counts in it are that
panel's — so the key doubles as the per-slice category breakdown rather than
being repeated boilerplate.

## The two filters are not the same filter

**σ — "predicted error."** Each source's own `thermodynamics[label][1]`, its
self-reported error bar, uncalibrated and on its own private scale.

**ê — "tolerance."** The calibrated expected \|error vs TECRDB\| from
`optimize_thermo_source_assignment.py`: σ pushed through an isotonic regression
fitted on 802 stereo-exact TECRDB matches, so the number is in real
kcal/mol-of-actual-error. ê is NaN — so the reaction always fails — where that
model refuses the source outright (eQuilibrator sentinels, dGPredictor-ModelSEED
on quinone/quinol).

σ ≤ 2 means "the source claims 2". ê ≤ 2 means "the source has been measured to
be off by about 2". They do not select the same reactions.

## The oval

Minimum-volume enclosing ellipse (Khachiyan) over the **passing** points — the
tightest oval that genuinely covers all of them, not a confidence ellipse. In
`context` mode the grayed-out failing points sit outside it by construction; the
oval's shrinkage from panel to panel is the filter's actual effect on the cloud.

## What the Convention A rebuild did, and did not do

GC values changed on **53%** of the reactions the two snapshots share, coverage
rose 25,812 → **27,313**, and the reported σ roughly doubled (median 5.06 →
10.28) because the new resolver reports `sqrt(mean(σᵢ²) + var(dgᵢ))`, widening
the bar when a compound's aliases disagree instead of collapsing it.

**The convention mismatch was tested, not assumed.** GC now ships Convention A
while eQuilibrator and dGPredictor-ModelSEED are still Convention B, and mixing
conventions costs (Δn_H − n_transported_H+) × 9.539 kcal/mol. If that leaked
into these panels it would show as a proton-proportional offset. It does not:
regressing the GC−eQuilibrator residual on net H+ gives a slope of **−2.67**
kcal/mol per proton, nowhere near ±9.539 — and it *shrank* from −3.39 under the
old mixed-convention GC. Consistent A against consistent B cancels for
mass-balanced reactions; what the rebuild fixed was convention mixing *inside*
single reactions. So the panels use raw stored values with no correction.

**Agreement improved slightly; accuracy against experiment did not.**
GC vs eQuilibrator median \|Δ\| 2.78 → **2.62** kcal/mol (r unchanged at 0.86).
But against TECRDB the rebuilt GC is the same as before — median \|err\| 1.60 →
1.57, within-2 kcal 57.7% → 56.6%, ρ(σ, \|err\|) +0.161 → **+0.176**. The
rebuild was a correctness and coverage fix, not an accuracy fix, and it did not
make GC's error bar informative.

## Four things the slices show

**1. eQuilibrator vs dGPredictor-ModelSEED is the pair that responds.**
r 0.86 → 0.99 at σ ≤ 1 (n = 3,390, 17% of the pair) and 0.998 at ê ≤ 1
(n = 1,291), median \|Δ\| 3.74 → 0.46 kcal/mol. The oval collapses onto the
diagonal. Untouched by the GC rebuild.

**2. Group Contribution's σ is still too weak to filter on, but it is no longer
counterproductive.** Against measured TECRDB error it is weakly informative:
ρ = +0.176 (p = 6e-07), and the decile profile is still non-monotone (0.71,
0.95, 1.79, 1.60, 4.27, 8.30, 1.91, 1.42, 1.25, 2.05). What changed is the low
end: GC vs eQuilibrator now reads median \|Δ\| 0.88 / 1.58 / 2.46 at σ ≤ 1 / 2 / 5
against a pooled 2.62 — monotone, and every tier better than pooled. Under the
old GC, σ ≤ 5 gave **3.47** against a pooled 2.78, i.e. tightening the filter
made the surviving set *worse*. That anomaly is gone. It costs coverage: σ ≤ 5
now keeps 4,155 reactions where it used to keep 8,359, because σ doubled.

On ê nothing improved. The isotonic fit still sees a flat relationship over its
combined target (ρ = −0.078 there, against 802 gold TECRDB points plus 9,793
silver ones targeting the proxy \|GC − eQ\| — that number is about the *fitting
target*, not about measured error, and should not be quoted as GC's error
correlation). ê_GC still floors at 3.04, so every GC panel at ê ≤ 2 is empty.

**3. Some empty panels are structural.** A panel is empty when no reaction has
*both* sources under T — which is not the same as either source's own floor.
The smallest T at which any reaction passes: GC vs eQ σ 0.54 / ê 3.04; GC vs
dGPMS σ 0.87 / ê 3.04; eQ vs dGPMS σ 0.87 / ê 0.56. Each empty panel prints its
own value in the footnote.

**4. Read the low-σ GC vs dGPredictor-ModelSEED panels with care.**
At σ ≤ 1, **95%** of the surviving reactions are ΔG′° = 0 in *both* sources
(68% at σ ≤ 2) — transport and net-cancelling reactions, where agreement is
free. That is why median \|Δ\| reads 0.00 there. Every panel prints its
ΔG′°-=-0-in-both share in the lower right; `slice_counts.tsv` carries it as
`frac_both_zero`.

## Base set

Per pair: reactions where both sources have a non-sentinel ΔG′° and a defined
(non-`?`) stored operator. eQuilibrator sentinels (σ > 100 kcal/mol, 4,934
values) are dropped up front. Reactions with \|ΔG′°\| > 1500 kcal/mol in either
source are dropped (9 / 19 / 11 per pair) — a single such point would set the
oval by itself. Base sizes: GC∩EQ **18,157**, GC∩DGPMS **25,950**, EQ∩DGPMS
19,731.

Point color is the reversibility transition between the two sources, in the same
definition and palette as `plot_thermo_source_dg_scatter.py`.

## Note on `../thermo_source_dg_scatter/`

That older directory shows the same three pairs but is **not** comparable: it is
built from the local `claude-changes` checkout, keeps eQuilibrator sentinels,
uses the original KEGG-mapped dGPredictor rather than the retrain, and reports a
Pearson r computed over points it does not draw (its own footnote carries the
shown-range r, which is the comparable number). Prefer the figures here.
