What this is

Each core model is evaluated with the ModelSEED/KBUtilLib Template Evaluation Suite (FVA reaction classification, closed-mode loop detection, and producible/consumable-metabolite sweeps) under four ways of assigning reaction directionality:

  • Default — the model's own in-place bounds (no override).
  • Jankowski — group-contribution thermodynamics (Henry-2007 feasibility rule); Jankowski_2008 column.
  • Flamholz 2012 — eQuilibrator reversibility index; Flamholz_2012 column.
  • Claude Opus 4.8 — LLM-predicted directionality; LLM_Opus_4.8 column.

Directions come from results/reaction_directions_literature_vs_llm.tsv; each method uses its own rule (not the MSDB cascade). A direction is applied by rewriting a reaction's bounds (>→(0,1000), <→(-1000,0), =→(-1000,1000)); NA/? leave the model's bound unchanged. Data: site/data/template_quality_all.json (built by scripts/template_quality_heuristics.py).
